## 📌 About the Internship

The internship focused on building a strong practical foundation in cloud computing using **Amazon Web Services (AWS)**, covering cloud foundations and cloud architecting — cloud economics and global infrastructure, security and networking, compute/storage/database services, elasticity and monitoring, IAM and VPC design, decoupled and serverless architectures, and disaster recovery planning. It followed a structured, week-wise curriculum combining conceptual learning with hands-on labs, weekly assessments, and project documentation, culminating in a Final Assessment Test.

**Organization:** EduSkills Academy (ISO 9001:2015 & ISO/IEC 20000-1:2018 certified) — runs the AICTE–EduSkills Virtual Internship Program under the patronage of the **AICTE National Internship Portal**, with curriculum provided by **AWS Academy**.

---

## 🎯 Objectives

- Understand core cloud concepts, economics, and billing, and explore the AWS global infrastructure
- Learn cloud security, networking, and content delivery for secure and efficient cloud solutions
- Gain practical knowledge of AWS compute, storage, and database services
- Implement automatic scaling and monitoring to optimize performance and manage resources
- Learn cloud architecture principles, IAM security, S3 storage, EC2 compute, RDS databases, and VPC networking/peering
- Secure access using IAM and KMS, and implement monitoring, elasticity, and high availability with EC2 and Route 53
- Build decoupled architectures using Amazon SQS and design serverless microservices with AWS Lambda
- Understand data engineering patterns, disaster recovery planning, and prepare for the AWS Solutions Architect certification
